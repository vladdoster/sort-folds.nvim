                SortFolds - sort folds by their first line

==============================================================================
USAGE                                   *SortFolds* *SortFolds-usage*

    Sorting |folds| is not easily possible in vanilla vim. You could join all
    lines in a fold, sort and split them up again; however, it is time
    consuming and tedious.

    This little plugin solves that issue: It sorts a visually selected region
    while keeping closed folds intact. Since folds can be created in a variety
    of ways (|fold-methods|), it is therefore straight-forward to sort
    arbitrary groups of text based on their first line.

    One use-case is to sort functions alphabetically after the fact.

    NOTE: This plugin was not tested and is not expected to work with
    `foldmethod` set to `manual` for now.

==============================================================================
COMMANDS                                *SortFolds-commands*

                                        *:SortFolds*
:SortFolds [line]       Sort folds in the selected range. Optional [line]
                        argument specifies which line within each fold to use
                        for sorting (0-indexed, default: 0).

==============================================================================
MAPPINGS                                *SortFolds-mappings*

    Currently there is only one binding - |<Plug>SortFolds| - that needs to be
    bound in visual mode. The default is:

                                        *<Plug>SortFolds*
>
    vmap <Leader>sf <Plug>SortFolds
<
    Then visually select the region you want to sort and use the mapping.


    Alternatively, you can visually select a region and use the command:
>
    :'<,'>SortFolds

==============================================================================
SORTING BY OTHER LINES IN FOLD          *SortFolds-custom-sort-line*

    Per default folds are sorted based on the contents of the first line in
    each fold. If, for some reason, you need to sort folds by the contents of
    another line, you can do by directly calling `:SortFolds` with
    the given line number. Lines in folds are zero-indexed. That means to sort
    based on the 42nd line you would use:
>
    :'<,'>SortFolds 41

==============================================================================
CONFIGURATION                           *SortFolds-configuration*

                                        *SortFolds-setup*
                                        *sort-folds.setup()*

    The plugin can be configured using the `setup()` function in Lua:
>lua
    require('sort-folds').setup({
      ignore_case = false,      -- Set to true for case-insensitive sorting
      key_function = nil,       -- Name of custom key function (optional)
    })
<

                                        *g:sort_folds_ignore_case*

    You can also ignore case when sorting using a global variable:
>vim
    let g:sort_folds_ignore_case = 1
<
    Default is 0

==============================================================================
CUSTOM KEY FUNCTIONS                    *SortFolds-custom-key-function*

                                        *g:sort_folds_key_function*

    Sometimes you need to sort folds by some custom key. For this reason, you
    can define a custom sort function in Lua that maps fold contents to a key
    (a string or number) by which the fold will be sorted.

    Afterwards, you need to set |g:sort_folds_key_function| to the name of the
    function, or use the `setup()` function with the `key_function` option.

    Example: Sort BibTeX-entries by citekey~

    BibTeX-entries can be of several types (`article`, `book`,
    `inproceedings`, `online`, to name a few…). However, we might want to sort
    them by citekey regardless of type.

    Hence, we might add a piece of code to extract the citekey:
>lua
    local sort_folds = require('sort-folds')
    
    sort_folds.register_key_function('get_citekey', function(fold)
      local first_line = fold:get_line(0) or ""
      local after_brace = first_line:match("{([^}]*)")
      if after_brace then
        local key = after_brace:match("([^,]*)")
        return key or ""
      end
      return ""
    end)
    
    -- Set globally
    sort_folds.setup({ key_function = 'get_citekey' })
    
    -- Or for specific filetype
    vim.api.nvim_create_autocmd('FileType', {
      pattern = 'bib',
      callback = function()
        vim.g.sort_folds_key_function = 'get_citekey'
      end
    })
<
    Note: `get_citekey` is already part of the |SortFolds-builtin-key-functions|

==============================================================================
BUILTIN KEY FUNCTIONS                   *SortFolds-builtin-key-functions*

    `get_citekey`   Map a BibTeX-entry to its citekey.

==============================================================================
LUA API                                 *SortFolds-lua-api*

                                        *sort-folds.sort_folds_range()*
sort-folds.sort_folds_range({start_line}, {end_line}, {sort_line})
    Sort folds in the specified range.
    
    Parameters: ~
      • {start_line}  (number) Starting line (1-indexed, inclusive)
      • {end_line}    (number) Ending line (1-indexed, inclusive)
      • {sort_line}   (number) Line to sort by within each fold (0-indexed)

                                        *sort-folds.sort_folds()*
sort-folds.sort_folds({sort_line})
    Sort folds in the visual selection.
    
    Parameters: ~
      • {sort_line}   (number) Line to sort by within each fold (0-indexed)

                                        *sort-folds.register_key_function()*
sort-folds.register_key_function({name}, {func})
    Register a custom key function for sorting.
    
    Parameters: ~
      • {name}  (string) Name of the function
      • {func}  (function) Function that takes a fold object and returns
                          a sortable key (string or number)

==============================================================================
REQUIREMENTS                            *SortFolds-requirements*

    SortFolds requires Neovim 0.5.0 or later with Lua support.
